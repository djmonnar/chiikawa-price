처음 한 번: 저장 설정

사이트에서 바꾼 목록을 GitHub에 저장하려면 열쇠 두 개가 필요해요. 값은 직접 넣어 주세요.

  1. GitHub 새 토큰 만들기 → Repository access: Only select repositories → chiikawa-price → Permissions에서 Contents와 Actions를 Read and write로 → Generate
  2. Vercel → chiikawa-price → Settings → Environment Variables에 두 개 추가: GITHUB_TOKEN = 방금 만든 토큰, ADMIN_PASSWORD = 이 화면에서 쓸 비밀번호
  3. Vercel → Deployments → 맨 위 배포의 ⋯ → Redeploy
